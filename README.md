## 👤 About

Software engineer since 2010, based in Asturies (Spain). I work where
**traditional music meets technology**.

My main line is **Automatic Music Transcription (AMT)** — polyphonic piano
transcription in particular — within **Music Information Retrieval (MIR)** and
**Digital Humanities**, with the Asturian bagpipe (*gaita*) as a separate
interest. This is the subject of my ongoing PhD research.

I publish **in the open**: field notes, prototypes, code and mistakes included.
What has no publishable material yet is marked as such — silence is data too.

## 🤝 Digital Bond

I build software under the
[**Manifesto of the Digital Bond**](https://xiringase.com/manifiestu)
(*Manifiestu del Vínculu Dixital*, October 2026): the person using what I make
is **a partner, not a metric**.

```mermaid
flowchart TD
    P(["Person"]) --> S["Sovereign bond"]
    S --> C["Count without identifying<br/>memory for value, amnesia for identity"]
    S --> H["Human approval<br/>nothing is published in bulk unchecked"]
    S --> V["Architecture over promise<br/>verify what is served"]
    S --> N["No behavioural tracking<br/>no cross-site data, no dark patterns"]
```
